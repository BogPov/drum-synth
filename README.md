# Синтез звука удара по барабанной мембране

## Описание проекта

Программа на Python моделирует колебания круглой барабанной мембраны после удара и сохраняет полученный звук в WAV-файл.

В основе модели лежит двумерное волновое уравнение с затуханием. Для его решения используется конечно-разностный метод. Звуковой сигнал формируется путём записи колебаний мембраны в выбранной точке.

## Как работает программа

1. Получает параметры моделирования из командной строки.
2. Создаёт двумерную сетку и выделяет круглую область мембраны.
3. Задаёт начальное возмущение, имитирующее удар.
4. Рассчитывает распространение колебаний с учётом затухания.
5. Записывает колебания в выбранной точке мембраны.
6. Нормализует сигнал и добавляет плавное затухание в конце.
7. Сохраняет результат в монофонический WAV-файл с 24-битными PCM-отсчётами.

## Математическая модель

Колебания мембраны описываются уравнением:

$$
\frac{\partial^2 u}{\partial t^2}
2\gamma\frac{\partial u}{\partial t}
= c^2 \nabla^2 u
$$

где:

- $$\(u\)$$ — смещение мембраны;
- $$\(\gamma\)$$ — коэффициент затухания;
- $$\(c\)$$ — скорость распространения волн;
- $$\(\nabla^2u\)$$ — пространственный лапласиан.

Скорость распространения волн вычисляется по формуле:

$$
c = \sqrt{\frac{T}{\rho}}
$$

где $$\(T\)$$ — натяжение мембраны, а $$\(\rho\)$$ — её поверхностная плотность.

Пространственные производные аппроксимируются конечными разностями. Временной шаг выбирается с учётом условия устойчивости численной схемы. На границе мембраны смещение принудительно обнуляется.

Удар моделируется гауссовым распределением начальной скорости. Во время расчёта программа последовательно обновляет поле смещений и сохраняет его значения в точке регистрации.

## Параметры запуска

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `--name`, `-n` | `sound` | Имя выходного файла без расширения |
| `--radius`, `-R` | `0.15` | Радиус мембраны, м |
| `--grid`, `-N` | `140` | Число узлов по каждой оси |
| `--tension`, `-T` | `2000.0` | Натяжение, Н/м |
| `--density`, `-rho` | `0.2` | Поверхностная плотность, кг/м² |
| `--gamma`, `-g` | `22.0` | Коэффициент затухания, 1/с |
| `--duration`, `-t` | `0.6` | Длительность моделирования, с |

Параметры позволяют изменять геометрию мембраны, её физические характеристики, разрешение расчёта и длительность синтеза.

## Установка

Требуется Python и библиотеки из requirements.txt:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Для изменения параметров используйте аргументы командной строки:

```bash
python main.py --name drum --radius 0.15 --grid 140 --duration 0.6
```

Чтобы посмотреть все доступные параметры:

```bash
python main.py --help
```

После завершения расчёта программа сохраняет результат в WAV-файл с указанным именем.

## Выходные данные

Программа создаёт аудиофайл со следующими характеристиками:

- формат: WAV;
- каналы: 1 (моно);
- глубина: 24 бита на отсчёт;
- частота дискретизации: определяется шагом времени моделирования.

Перед сохранением сигнал центрируется относительно среднего значения, нормализуется и плавно затухает в конце.

## Ограничения

- Мембрана считается однородной, а её натяжение — постоянным.
- Удар задаётся начальным распределением скорости, без моделирования контакта с барабанной палочкой.
- Граничное условие реализовано приближённо через обнуление узлов вблизи края.
- Звук формируется по смещению одной точки мембраны. Распространение звуковых волн в воздухе не моделируется.
- Нормализация сигнала не позволяет напрямую судить об абсолютной амплитуде физических колебаний.
